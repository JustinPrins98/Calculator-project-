# Calculator

This project is part of The Odin Project Foundation Course. The goal is to create a functional calculator application using JavaScript, HTML, and CSS. This project focuses on integrating logic with a user interface while reinforcing foundational programming concepts.

---

## Learning Objectives

- **Basic Arithmetic Operations:** Implement addition, subtraction, multiplication, and division functionality.
- **DOM Manipulation:** Dynamically update the display and manage user interactions.
- **Event Handling:** Handle button clicks to perform calculations.
- **Modular Code Structure:** Write clean, reusable functions for performing operations and managing state.
- **Error Handling:** Prevent invalid inputs, such as division by zero.
- **UI/UX Design:** Create a visually appealing and user-friendly calculator interface.

---

## Features

- **Basic Operations:** Perform addition, subtraction, multiplication, and division.
- **Clear Button:** Reset the calculator display and all stored values.
- **Keyboard Support:** Allow users to input numbers and operations using the keyboard (if implemented).
- **Chained Operations:** Perform calculations sequentially without clearing the display.
- **Responsive Design:** Ensure the calculator works on various screen sizes.
